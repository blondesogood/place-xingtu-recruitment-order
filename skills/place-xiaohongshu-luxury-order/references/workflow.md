# 网页流程

## 下单并回填

1. 绑定原授权集合并逐单取得锁。打开内部订单列表，识别顶部当前角色；已有商务角色时自动切换。查询指定订单，要求本次请求响应与对应行一致。同值查询先点击真实清除按钮、等待清空响应，再重新填写。
2. 核对小红书、奢品业务、图文及达人内外 ID。内部已有任务 ID 直接读合作详情，核对映射、达人、主体及广告主账户；合作名称可以不同。
3. 无任务 ID 按固定标题和达人查全唯一结果；多条不选，唯一结果仅恢复回填。不存在且无未决动作时才创建。
4. 购物车只能有当前达人唯一图文条目。空车才从真实达人主页加购；保留并核对条目 ID，再进入提案。提案必须仅含当前达人，核验后填写模板、合作名称、日期、协商价格、60 天及双 SPU。混入他人条目不改不删，记录该单失败。
5. 打开提交预览后重新核对内部同单事实、表单和提案成员；最终按钮前原子写入 CREATE 标记。开发 preview 返回，不点击最终按钮。实际创建后从平台重新查询唯一合作。
6. 回填前重新读内部行及外部归属，选定上海悦川账户；最终保存前写入 WRITEBACK 标记，随后回读内部持久结果。
7. 输出待接单或待支付等逐单结果。ORDER 不付款。

## 检查接单并支付

1. 读取原授权批次或子集；按同一内部任务 ID 重新核对合作。缺少映射不进入下单流程。
2. 未接单记 WAITING_ACCEPTANCE；已付款、完成或关闭分别终止付款；继续其他订单。
3. 待支付且业务符合时，核对内部商务已下单、账户、任务 ID、达人、主体、双 SPU 和金额。服务费必须为内部金额 10%，总额必须为 110%，误差为零。
4. 点击“立即支付”进入金额弹窗；再次读取当前内部及外部同单事实（保留弹窗），核对弹窗金额。条件满足后原子写入 PAY 标记并点击弹窗“确定”。preview 在该按钮前返回。
5. 只以同单平台终态完成对账；结果未知保留标记，绝不再次付款。不得点击“取消合作”。

## 异常

单笔范围不符、字段不一致、购物车混入、查询失败或结果未知均有明确原因，继续其他独立订单。只有登录、验证码、平台风控和缺少必要角色／访问权限属于本人处理；页面加载和普通角色切换由执行器恢复。
