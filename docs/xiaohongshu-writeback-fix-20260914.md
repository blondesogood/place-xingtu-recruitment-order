# rc.16 回填保存响应修复

修订：`2026-09-14-writeback-response-v1`。问题与历史证据见[诊断记录](xiaohongshu-writeback-diagnosis-20260914.md)。

## 行为变化

此前点击保存后立即导航查询，可能中断异步请求且丢失错误提示。现在点击前启动网络观察，按内部记录 ID、外部任务 ID、广告主 ID 精确匹配保存 POST，在原页面等待匹配请求完成，再查询持久结果。

HTTP 拒绝、应用拒绝、网络取消、前端校验失败、请求未观察到、响应超时及响应不可读分别报告。脱敏状态和数字返回码以 attemptId 关联保存在 lastActionEvidence，不保存凭据、请求正文或后台错误原文。点击调用本身报错后仍观察已可能发出的请求；最终点击始终仅一次。

成功 ACK 不清除 WRITEBACK 未决：仍须内部平台回读同一任务 ID、商务已下单和上海悦川账户。失败、超时或原始未决均不会自动重放保存。没有修改原验收单的恢复记录，也没有新增真实下单或付款。

## 验证结果

- 先用旧的点击后立即返回逻辑运行 `node --test scripts/writeback-submit.test.mjs`，断言“保存完成前不得返回导航”失败；替换响应等待后通过。
- 最终 `node --test scripts/*.test.mjs`：36/36 通过，覆盖精确匹配、慢响应、HTTP／应用拒绝、网络取消、表单校验、缺请求、超时、不可读响应、点击传输错误、持久证据与旧未决防重。
- Ego Lite + 实际 EgoDriver + 新 submitWriteback，本机服务器延迟 500ms，连续十次点击后导航：received=10、committed=10、aborted=0，十次均 ACKNOWLEDGED。
- 浏览器夹具只连接 localhost；测试桥将本机 CDP 请求事件中的 origin 转换为生产匹配器的 origin，其他事件来自实际浏览器。该转换仅用于夹具，不在运行代码中；错误 origin／记录 ID／任务 ID／账户另有单元测试。夹具不证明生产接口及同事电脑已验收。
- 本机安装与源码运行文件逐项一致，Manifest 校验通过。旧 ZIP 未更新。

夹具服务器为 `scripts/test-support/writeback-browser-server.cjs`，在 127.0.0.1:18864 运行；仅用于开发验证，不随安装包分发。浏览器测试完成后已关闭测试空间并停止服务器。
